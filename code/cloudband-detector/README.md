# Cloudband Detector: Weakly Supervised Marine Cloud Regimes

**Venue:** Coastal Systems Conference 2025

**Authors:** Elena Marsh, Tomas Varga

**Summary:** Weakly supervised detector for marine cloud-band regimes in geostationary imagery.

## Repository Status

Released. This repository contains the reference implementation used in the paper. The code, training scripts and evaluation utilities are publicly available in this repository under the MIT license.

## Contents

- `src/` - model, training and evaluation code
- `data/` - data preparation notes
- `experiments/` - configuration files
- `results/` - released metrics
